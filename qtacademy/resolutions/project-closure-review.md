# 关于课题结项初审机制的决议

实训基地代表大会根据公司授权，经代表共同讨论并结合实际课题初审试运行情况，决定建立课题结项初审机制，并按照本决议行使课题结项初审权。

## 一、审核原则

课题结项初审以经批准的原立项方案为基础，对课题实际交付情况进行审核。

审核主要遵循以下原则：

1. 以原立项承诺、原验收条件、实际交付成果和可验证证据作为判断依据；
2. 不补充申请人未提供的事实，不自行推定未被证明的结果；
3. 不在结项阶段临时增加原立项之外的验收标准；
4. 超出原立项范围的额外交付可以作为成果记录，但不能替代原立项承诺和验收条件。

## 二、审核内容

课题结项初审主要审核以下内容：

1. 原立项核心工作是否完成；
2. 原立项验收条件是否达到；
3. 实际交付成果是否成立；
4. 成果在实际工作场景中是否能够使用。

代表应根据实际成果和证据形成明确判断。证据不足、无法支持判断的事项，应明确记录为无法判断，不得通过推测补充。

## 三、协作机制

每个申请结项的课题，由实训基地代表共同参与初审。

代表根据课题内容和各自专业能力分工审核，并可以对其他代表负责的审核内容进行补充和复核。

为减少重复劳动，已由主审代表完成并提供充分依据的审核内容，其他代表原则上无需重复完成相同审核工作。

秘书负责组织初审，包括建立协作文档、整理原立项核心工作和验收条件、协调审核分工、推进审核进度以及汇总审核结果。

秘书负责组织和汇总，不代替其他代表作出审核判断。

## 四、协作与记录

课题结项初审使用共同的协作文档开展。

各代表在同一份协作文档中记录所负责事项的实际结果、证据和判断，其他代表可以查看并补充。

协作文档作为初审过程中的工作材料，由代表在飞书中共同维护。

## 五、初审结论

课题结项初审形成以下两种结论之一：

- 通过
- 驳回

各项审核完成后，由秘书根据代表已经形成的审核意见汇总初审结论。

代表对结论存在分歧时，优先通过讨论形成共识；无法形成共识时，通过投票表决形成最终初审结论。

经代表确认后，该结论作为实训基地代表大会对该课题形成的正式初审结果。

## 六、执行

本决议通过后，实训基地代表大会按照本机制开展课题结项初审。

《课题结项初审协作文档》作为本机制的执行工具，由代表在实际审核过程中共同使用和维护。

本机制在实际运行中发现新的协作问题时，可由代表再次发起议事并通过新的决议进行调整。
