实训基地自建账本规则（决议草案）

- 日期：2026-09-15
- 状态：草案（征求意见中）
依据（群内公开记录）：
- 张果 2026-09-10 14:33：「实训基地可自建独立账本，自己搞积分兑换，只要是基地通过的正式决议就可以；公司层面会与基地账本对应（公司账本以代金券为核心、以课程服务为发券基准）」
- 张果 2026-09-10 14:34：「基地呢，你要想让你的账本有信用，那就靠你们自己了」
- 现状衔接：于鸿伟 9-10 上线的任务积分制是代金券制度的雏形；赵子奕 9-10 提出代金券转赠需求（分包场景）
一、要解决的问题
实训基地成员的贡献目前散落在群聊记录和各处 Issue / PR 里，没有统一账本：
1. 谁贡献了什么、累计多少，无法一句话查清；
2. 代金券的发放、兑换、转赠没有公开可核对的记录；
3. 基地账本与公司账本无法对应核对。
二、方案：一份入仓库、可溯源的账本
1. 记账单位与口径
- 以代金券为记账单位，1 代金券 = 1 元，与公司口径一致。
2. 记账范围（初版，待决议增删）
- 课题立项 / 结项奖励
- 任务接取与完成（与任务积分制对接）
- 代表大会与初审工作（课题结项初审、秘书工作等）
- 其他经代表大会决议确认的贡献
3. 记账流程
1. 发起：任何成员可发起记账条目（格式见下）；
2. 确认：条目须附来源链接（群消息 / Issue / PR），代表大会决议通过后入账；
3. 入账：账本以 Git 提交落在本仓库，改动留痕、可回溯；
4. 异议：入账后有异议的，走「提案 → 代表大会决议 → 更正」流程，不直接修改历史条目。
记账条目格式：
日期 | 成员 | 事项 | 券额 | 来源链接
4. 转赠规则（初版）
- 允许代金券转赠（覆盖分包协作场景）；
- 转赠需双方在群里确认后，按上述流程记账。
5. 公开与对应
- 账本文件存于本仓库（草案期在 drafts/，决议通过后移入正式目录）；
- 基地账本建议按周与公司账本核对一次。
三、验收标准（决议通过后 30 天内检验）
      项
      标准
      S1 溯源
      100% 条目附来源链接
      S2 及时
      贡献发生 → 入账 ≤ 7 天
      S3 对应
      基地账本与公司账本按周核对，差异 = 0
      S4 独立运行
      至少 1 个完整记账周期由代表大会以外成员发起（流程不依赖单一人物）
四、待代表大会决议的事项
1. 记账范围增删（如：知识库维护、宣传任务是否入账）；
2. 各事项的具体券额数值（建议决议中定死数值，不留"酌情"）；
3. 账本管理员人选（建议由秘书或轮值代表承担；账本操作走 PR，任何人可 review）。
